# Design decisions

Design questions are decided by **Rudolf**, a design persona built from Rudolf Steiner's published
*method*: percept + concept (*Truth and Knowledge* 1892, *The Philosophy of Freedom* 1894), Goethe's
phenomenon-first science, threefolding (1919), Imagination / Inspiration / Intuition used as a
three-pass pattern, and the Rückschau review. It is an ATTRIBUTED, interpretive lens, not Steiner
speaking. His clairvoyant content claims (including the Akashic Chronicle) are not treated as fact,
and his racial teachings are rejected outright. The project owner can overturn any ruling.

| # | Question | Ruling |
| --- | --- | --- |
| D1 | What counts as true? | Evidence **and** connection. CORROBORATED needs the gravity rule plus at least one typed edge to a non-METAPHOR gene, or an ANSWERS edge to a charter. Evidenced orphans stay HYPOTHESIS, flagged `unintegrated`. |
| D2 | Authority or replication? | Method over rank. Weight comes from evidence type and demonstrated track record; titles add nothing. |
| D3 | The owner's own ideas | Free to enter (they jump the queue), equal before the gate. |
| D4 | Esoteric material | Mapped on its own terms (ATTRIBUTED), experiences as PHENOMENOLOGICAL, tested wherever a checkable claim appears. |
| D5 | Resonance mark | Adopted. Owner's mark affects priority and reading order only; the gate never reads it. |
| D6 | PHENOMENOLOGICAL frame | Adopted as a sixth frame. Corroborated *as reports*, across independent practitioners; linked to other frames only via PARALLELS. |
| D7 | Gravity strictness | Keep k = 2 → 3 → 4, capped at 4. |
| D8 | First charter | "How can machine-assisted research know that it knows: extract faithfully, judge fairly, connect truly?" |
| D9 | Source independence | Must be shown, not presumed. Lineage = origin of the percept (same dataset, experiment, quoted passage or author group), domain only as fallback; doubtful pairs merge. |
| D10 | Source reliability | From transparency (data, methods, code shown), resolved predictions and executed checks. Agreement with the library never raises it. |
| D11 | Synthesis (DERIVED genes) | Must state one novel, checkable consequence; the Forager hunts it, and a thorough null search adds ABSENCE evidence against. |
| D12 | Memorisation | Pictures before lists: each cluster delivered as an image, its archetype gene in one sentence, and its metamorphosis trail. |
| D13 | 24/7 rhythm | Daily forage + Rückschau, weekly meta-review, quarterly charter review; a charter without progress for a season pauses. |
| D14 | Uncertain judge | Keep both genes and link them RELATED; never SAME below the confidence threshold. |

Code catches up with D1, D5, D6, D9 and D10 in Phase 1–2; Phase 0 code predates these rulings.
